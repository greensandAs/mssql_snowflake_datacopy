# Logo Assets

This directory contains Tiger Analytics logo files for Streamlit apps.

## Current Files

| File                       | Purpose                              | Status      |
| -------------------------- | ------------------------------------ | ----------- |
| `ta_logo_light.svg`        | Logo for light/white backgrounds     | PLACEHOLDER |
| `ta_logo_dark.svg`         | Logo for dark/navy backgrounds       | PLACEHOLDER |
| `ta_logo_monochrome.svg`   | Single-color logo for footers/print  | PLACEHOLDER |
| `ta_favicon.png`           | 32×32 favicon for browser tabs       | NOT YET ADDED |

## How to Replace

1. Obtain the official Tiger Analytics logo files from the **Marketing & Communications** team or the internal brand portal.
2. Export each variant as **SVG with transparent background**.
3. For the favicon, export a **32×32 PNG** with transparent background.
4. Replace the placeholder files in this directory, keeping the same filenames.

## Logo Requirements

- **Minimum display width**: 80px
- **Transparent background**: Required for both light and dark mode support
- **Do not modify**: Colors, proportions, rotation, or effects
- **Clear space**: Maintain padding equal to the height of the "T" in "Tiger" on all sides
